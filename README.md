Brainrot Hunter — tangkap semua brainrot! Game kolektor/simulator Roblox di dunia 3D: jelajahi 4 zona, tangkap 24 karakter brainrot yang berkeliaran, dan tiap karakter yang kamu tangkap menghasilkan Koin per detik. Belanjakan Koin untuk upgrade Magnet, Sepatu Kilat, dan Keberuntungan di plaza, lalu buru Golden Tung Tung MYTHIC yang muncul berkala di zona acak. Gratis dimainkan, tanpa Game Pass. Mainkan di [Brainrot Hunter](https://www.roblox.com/games/138667510223673/Brainrot-Hunter).

## Run it

Buka `game.rbxl` di Roblox Studio lalu tekan Play, atau mainkan gratis di [Brainrot Hunter](https://www.roblox.com/games/138667510223673/Brainrot-Hunter).
